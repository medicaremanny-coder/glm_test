# MedicareManny 2027 Comparison Engine

Permanent project home for the South Florida Medicare plan intelligence tool.

## Layers

- **Obsidian / Drive knowledge** — SOBs, carrier PDFs, hospital notes, training.
- **This repository** — rules, structured data, verification log, future app.
- **Google Sheet** — agent-facing MVP interface.
